Moving ownership from C to Rust without cloning

Published July 7, 2026 · 11 minute read · rust, c, ffi, performance

The event processing engine I'm building is written in Rust and integrates with an existing C codebase. It retains events for future correlation, so borrowing their data for a single FFI call is not enough: Rust must take ownership.
